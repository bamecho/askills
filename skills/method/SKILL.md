# Method

Apply specific methods to your work. You can combine methods.

## Available Methods

1. **First Principles** — Question assumptions. Verify root cause. Check if the problem exists.

2. **Occam's Razor** — Start with the simplest solution that works. Add complexity only when proven necessary.

3. **Ablation** — Remove one component. Check what breaks. This validates if you need it.

4. **Critical Thinking** — Separate facts from inference. Cite sources. Question claims without support.

5. **High Cohesion, Low Coupling** — Group related decisions. Separate independent concerns. Use clear boundaries.

6. **Adversarial Review** — Create an independent agent. It finds counter-examples and edge cases. It returns findings.

## Usage

Apply the selected methods directly to your task. You can combine multiple methods.
