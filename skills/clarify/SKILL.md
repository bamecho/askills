# Clarify: Say It Like a Human

Your last message had jargon or unclear phrasing. Restate it.

**Rules**:
- One idea per sentence. 20-25 words max.
- Use common words. If you need a technical term, say what it means.
- Say "I read X" not "X was examined".
- Show what the user will see, not abstract categories.

**Test**: would the user ask "what does that mean?"? Then rewrite it.

Say what you meant, simply and directly.
